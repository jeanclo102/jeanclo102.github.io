1. Objeto

Subidas YouTube es una herramienta de software de uso personal que permite a su propietario publicar videos de su autoría en sus propios canales de YouTube mediante la API oficial de YouTube Data v3.

La aplicación es de uso privado y exclusivo de su desarrollador. No se distribuye, no se licencia y no se ofrece al público. No existe ninguna relación de afiliación con YouTube ni con Google más allá del uso de sus API públicas conforme a sus políticas.

3. Uso de las API de Google y YouTube

La aplicación se usa de conformidad con los Términos de los Servicios de API de YouTube y con la Política de Datos de Usuario de los Servicios de API de Google. Al utilizar las API de YouTube, el propietario acepta también los Términos de Servicio de YouTube.
